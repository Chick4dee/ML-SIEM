# Контракт покрытия: класс атаки → ответственный эксперт

> Зачем: разбивка по ролям (Mixture-of-Experts) работает, только если для каждого
> типа атаки есть эксперт, который его реально видит. Этот документ фиксирует
> ожидаемое покрытие ДО сборки ансамбля, чтобы на фазе 7 (мета-слой) и фазе 21
> (оценка на лаб-данных) **проверять** покрытие по факту, а не надеяться.
>
> ⚠️ Важная оговорка: эксперты учатся на РАЗНЫХ датасетах (Э1—UNSW, Э2—CTU-13,
> Э3—CSIC, Э4/Э5—полигон). Поэтому «спасение» слабого класса происходит не на
> бенчмарке одного эксперта, а в живой системе, где одна атака проявляется в
> нескольких модальностях (flow + payload + host + аномалия). Покрытие проверяем
> на интегрированном лаб-трафике (фаза 21), а не переносом примеров между
> бенчмарками.

## Эксперты

| ID | Эксперт | Модальность | Датасет обучения |
|---|---|---|---|
| Э1 | Flow CNN+LSTM | статистика потока | UNSW-NB15 |
| Э2 | Temporal CNN+LSTM | периодичность/время (beaconing) | CTU-13 |
| Э3 | Payload char-CNN | содержимое запроса | CSIC 2010 (HTTP) |
| Э4 | CNN-LSTM Autoencoder | аномалия (volume/timing), open-set | benign полигона |
| Э5 | Host CNN+LSTM (HIDS) | действия на хосте | Sysmon (Caldera/GHOSTS) |

## Карта покрытия

| Класс атаки | Основной | Поддержка | Статус (baseline Э1, фаза 2) |
|---|---|---|---|
| reconnaissance / scan | Э1 | Э4 | ✅ Э1 силён (PR-AUC 0.92) |
| exploits | Э1 | Э3 (если payload), Э5 | ✅ Э1 хорошо (0.78) |
| shellcode | Э1 | Э3, Э5 | ✅ Э1 прилично (0.62) |
| fuzzers | Э1 | Э3 | 🟡 Э1 средне (0.48) |
| dos / ddos | **Э4** | Э1 | 🟡 Э1 слаб (0.15) → ждём Э4 (его зона) |
| backdoor / C&C | **Э2** | Э5, Э1 | 🟡 Э1 слаб (0.11); Э2 ОТЛОЖЕН до полигона |
| worms | Э3+Э5 | Э4, Э1 | 🟡 Э1 слеп (0.01) → ждём payload/host |
| analysis | Э1 (recon-like) | Э4 | 🟡 Э1 слаб (0.07); частично пересекается с recon |
| web (SQLi/XSS/brute) | **Э3** | — | ✅ Э3 обучен (CSIC PR-AUC 0.9998; single-app) |
| host (lateral/persist) | **Э5** | Э2 | ⬜ Э5 не обучен (фаза 20) |
| zero-day / unknown | **Э4 + open-set** | — | ⬜ фаза 3 (AE) + фаза 7 (open-set) |

## Известные пробелы (держать на карандаше)

- **generic** (UNSW; крипто-атаки против блочных шифров): нет естественного
  эксперта-владельца. Э1 даёт 0.30. Решение пока не определено — кандидаты:
  принять как «прочее»/слить в open-set, либо отдельный сигнатурный признак.
  Проверить на фазе 7.
- Перенос таксономии между датасетами (контракт #10) может оставить классы без
  единого соответствия — сверить при сборке мета-слоя.

## Как проверяем (критерий, не надежда)

- **Фаза 7 (мета):** для каждого класса измеряем, какой эксперт даёт основной
  вклад; класс без надёжного владельца = красный флаг покрытия.
- **Фаза 21 (лаб-данные):** прогон по интегрированному трафику; per-class recall
  по всей карте. Пробелы, не закрытые ансамблем, документируем честно.
